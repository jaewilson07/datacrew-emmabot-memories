# Domo AI Library — Conversational Agents Gotchas

- **Conversational Agents is a beta feature** — requires a request to Domo/CSM to enable. It is NOT automatically available even when AI Chat is enabled.
- **AI Library has two tabs**: "Toolkits" and "Agents". If only the "Toolkits" tab is visible, Conversational Agents is not enabled for the instance.
- **Toolkits visible by default**: User Administration, Domo Basic MCP, Cards
- **Grants for Conversational Agents**:
  - Edit Conversational Agents: Admin, Privileged, Editor
  - Manage Conversational Agents: Admin only
  - View Conversational Agents: Admin, Privileged, Editor, Participant
- **Navigation**: AI Library is found under AI and Machine Learning in the left navigation
- **Common DUG pattern**: users who can't find AI Chat should also ask their CSM about Conversational Agents beta access in the same conversation — both require backend provisioning
